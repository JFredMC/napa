Reglas que sigue el servidor

  • Revisa el robots.txt de cada tienda antes de pedir nada y respeta su intención. Si no lo puede leer, no consulta.
  • Solo APIs públicas u oficiales. No hace scraping, no se disfraza de navegador, no resuelve captchas y no rota IPs.
  • Solo consulta cuando alguien busca: como mucho una petición cada 2 s por tienda, caché de 1 hora y un User-Agent que se identifica con enlace al repositorio.
  • Para Éxito y Carulla solo pide, como mucho cada 12 h, el sitemap que su propio robots.txt anuncia, para comprobar si aceptan robots identificados. Nunca su /api/.
  • Si una fuente falla o la bloquean, esa tienda vuelve al simulado y la respuesta lo dice.
  • Los precios reales solo se comparan con precios reales.

Qué falta para más tiendas en vivo

  • Mercado Libre: una app registrada en developers.mercadolibre.com.co y su refresh token OAuth (la búsqueda puede seguir restringida por app).
  • Éxito y Carulla: permiso escrito de Grupo Éxito para el robot de Ñapa, o un convenio o feed de datos. Su robots.txt prohíbe /api/ y las búsquedas (solo quedaría rastrear su sitemap completo), su anti-bots rechaza robots identificados y los términos de exito.com son de uso personal.
  • D1, Ara, Alkosto, Falabella, Shein, Temu: un convenio, feed de afiliados o API oficial.
  • Una base de datos para que el historial de precios reales sobreviva a los reinicios (hoy vive en memoria).

Cómo decidimos si un descuento es real

  • Con al menos {{ minDays }} días de historial, el precio habitual es la mediana de hace 90 a 8 días.
  • Inflado: el precio “antes” nunca se cobró en 90 días (con {{ tolerance }} % de margen) o el precio de hoy no baja del habitual.
  • Dudoso: anuncia {{ suspicious }} % o más y no hay historial para comprobarlo.
  • Puntaje 0–100: ahorro real (35), frente a otras tiendas con envío (25), historial (15), confianza de la tienda (15) y envío (10). Un descuento inflado queda en máximo 30.

Ubicación y mapas

Las sedes cercanas salen de OpenStreetMap vía Overpass API (datos reales, © colaboradores de OpenStreetMap, ODbL). El mapa usa MapLibre con estilos de CARTO, sin llaves. Tu ubicación solo se pide cuando tocas el botón y no se guarda.
